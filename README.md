# 🍦 Ice Cream Parlour Billing System

## Project Overview
A web-based Ice Cream Parlour Billing System developed using HTML, CSS, and PHP.
The system generates customer bills and allows downloading invoices in PDF format using the FPDF library.

## Features
- Ice cream billing generation
- Automatic PDF invoice creation
- Downloadable bills
- Uses FPDF library

## Technologies Used
- HTML
- CSS
- PHP
- FPDF Library

## Note
Database credentials are intentionally not included for security reasons.
Replace placeholder values in config.php with your own database credentials before running.
